WHAT THIS VERSION DOES
- Shows a curated catalogue of 8 named products with direct Jumia Uganda product-page links.
- Product card photo, name and arrow open the exact Jumia listing rather than the TROP demo cart.
- Products are grouped into Electronics, Fashion, Home, Beauty and Sports.
- Product photos are served from Jumia's image CDN.
- Includes mobile-friendly layout, category filters, text search, favourites, PWA manifest and app icons.
- The header and footer include direct links to Jumia Uganda.

IMPORTANT LIMITATIONS
- This is a manually curated static catalogue, not a live Jumia API/feed integration. Product links and images were checked while preparing this package on 19 October 2026. Jumia may change prices, images, stock, product availability or URLs later. Visitors should check Jumia for the live price, options, shipping and stock.
- Price labels in TROP are snapshots taken from the linked Jumia pages, not live prices.
- TROP Market is an independent product-discovery page and is not owned or operated by Jumia. Do not imply an official partnership.
- Checkout and payment happen on Jumia. The TROP demo cart has been bypassed for shopping clicks.
- The old seller-listing interface is hidden in this Jumia-only edition so newly added random items do not appear in the catalogue without a Jumia match. To add future products, add an item only after verifying its exact Jumia Uganda product page, image and current listing.
- Supabase is not used by this static Jumia catalog build. The included supabase-config.js is retained only for continuity with the previous package and its public key placeholder remains unchanged.

PUBLISHING ON GITHUB PAGES
1. Extract this ZIP.
2. Upload the files and icons/ folder to the root of your existing GitHub Pages repository, replacing the old files.
3. Commit the changes and wait for GitHub Pages to redeploy.
4. Open the live site in Chrome and refresh. If the old version remains, close and reopen the site after deployment.

NEW IN THIS PACKAGE — CUSTOMER REVIEWS AND GOOGLE SETUP
- Click/tap a product image or name to open its details and review section. Use the arrow button or the “Shop this product on Jumia Uganda” button to go to the matching Jumia page.
- To let everyone share reviews across phones, set the public Supabase publishable key in supabase-config.js and run supabase_reviews.sql. New reviews need approval in Supabase before appearing publicly.
- Follow SETUP_README.txt for Supabase, Google Search Console, sitemap and robots.txt steps. Google indexing and ranking cannot be guaranteed.
